# 대사 파일 형식

`data/story/파일이름.json`은 한 줄씩 위에서 아래로 진행되는 배열이에요. 기획서의 예시 형식에 분기와 합류용 항목을 더했어요.

```json
[
  { "bg": "staff_room", "speaker": "교감", "face": "default", "text": "첫날부터 미안하네요." },
  { "choice": [
    { "text": "제가 뭘 해야 하는지 잘 모르겠어요.", "goto": "a" },
    { "text": "알겠습니다. 해볼게요.", "goto": "b" }
  ] },
  { "label": "a", "speaker": "교감", "text": "다들 몰라요.", "goto": "merge" },
  { "label": "b", "speaker": "교감", "text": "너무 애쓰진 마세요." },
  { "label": "merge", "narration": "(두 갈래가 여기서 다시 만난다)" }
]
```

## 보여주는 줄

| 항목 | 뜻 |
| --- | --- |
| `text` | 대사. `*(웃는다)*`처럼 별표로 감싼 부분은 기울임체 지문으로 보여요 |
| `speaker` | 이름표에 표시할 이름 |
| `aside` | 이름 옆 괄호 표시. `"독백"` → `선생님 (독백)` |
| `narration` | 지문. 이름표 없이 전체가 기울임체로 보여요 |
| `title` | 화면 가운데 큰 글씨 카드 (스테이지 클리어, 장소 표시 등). 줄바꿈은 `\n` |
| `note` | 손글씨 메모지 장면 (문에 붙인 안내문, 쪽지 등). `{ "lines": ["쉼표부", "아무것도 안 해도 됨."] }` → 메모지에 공책 줄마다 한 줄씩 써진다. `"add": ["혼자 오지 않아도 됨."]` 을 붙이면 `lines` 는 이미 쓰여 있고 `add` 줄들이 그 아래에 다른 색 펜으로 새로 써진다. 한 줄은 메모지 폭에 맞게 짧게 (12자 안팎) |
| `tutorial` | 튜토리얼 상자. `{ "title": "전투 시작", "text": "…" }` |
| `offstage` | `true`면 말하는 캐릭터를 무대에 올리지 않음 (문밖에서 하는 말 등) |

## 화면 바꾸기

| 항목 | 뜻 |
| --- | --- |
| `bg` | 배경 바꾸기. 값은 배경키 (`assets/README.md` 참고) |
| `show` | 무대에 세울 캐릭터를 왼쪽부터 최대 3명. `["seoyeon"]`, `[{ "id": "dahyeon", "face": "smile" }]`, 모두 내리려면 `[]` |
| `face` | 말하는 캐릭터의 표정. default, smile, sad, surprised, angry |
| `who` | 말하는 캐릭터 아이디를 직접 지정 (이름과 아이디가 다를 때) |

- `speaker`가 부원(`characters.json`)이나 조연(`npcs.json`)의 이름이면 자동으로 무대에 올라오고, 나머지 캐릭터는 어둡게 보여요.
- 무대에 이미 3명이 있으면 가장 왼쪽 사람이 내려가요.
- "선생님"처럼 목록에 없는 이름이 말하면 무대 위 캐릭터가 모두 어두워져요.

## 분기와 합류

| 항목 | 뜻 |
| --- | --- |
| `label` | 이 줄의 이름. `goto`로 여기로 올 수 있어요 |
| `goto` | 이 줄을 보여준 다음 해당 `label`로 이동. 보여줄 내용 없이 `{ "goto": "x" }`만 써도 돼요 |
| `choice` | 선택지 목록. 각 선택지에 `text`, `goto`(없으면 바로 다음 줄로), `if`, `set`, `remember`를 쓸 수 있어요 |
| `if` | 조건. 맞지 않으면 그 줄(또는 선택지)을 건너뛰어요. `"met_seoyeon"`, `["a", "!b"]`(a는 참이고 b는 거짓일 때) |
| `set` | 이번 플레이 동안만 기억하는 값. 파일을 다시 플레이하면 지워져요. 예: `{ "met_seoyeon": true }` |
| `remember` | 저장 데이터(`flags`)에 영구히 남기는 값. 나중 장에서 `if`로 확인할 수 있어요 |

파일을 불러올 때 없는 라벨로 가는 `goto`, 겹치는 라벨, 잘못된 `show`가 있으면 화면에 몇 번째 줄이 문제인지 표시돼요.

## 전투

```json
{ "battle": {
  "enemies": ["shade", "shade", "shade"],
  "party": ["seoyeon", "yuna", "eunchae"],
  "reserve": ["hayun", "jiyu", "dahyeon"],
  "tutorial": "prologue_3"
} }
```

- 이 줄에 오면 전투 화면으로 넘어가고, 이기면 바로 다음 줄부터 대화가 이어져요. 배경, 무대 위 인물, 대사 기록도 그대로예요.
- `party`는 전장에 나서는 3명, `reserve`는 대기 부원이에요. 대기 부원이 있으면 전투에 '교대' 버튼이 생겨요.
- `tutorial`은 `data/tutorials.json`의 튜토리얼 묶음 이름이에요.
- 전장의 세 명이 모두 쓰러지면 `data/story/prologue_wakeup.json`(또는 `"wakeup": "파일이름"`)을 보여줘요. 이 파일의 마지막 선택지에서 `"set": { "retry": true }`를 고르면 같은 전투를 다시 시작하고, 아니면 부실로 가요.

## 유대 올리기

```json
{ "title": "하윤과 지유의 유대가 1 올랐습니다.", "bond": { "pair": ["hayun", "jiyu"], "amount": 1, "once": "prologue_hayun_jiyu" } }
```

`once`가 있으면 같은 저장 데이터에서 한 번만 올라요. 스테이지를 다시 봐도 중복되지 않아요.

## 전투 튜토리얼 (`data/tutorials.json`)

| `when` | 뜨는 때 |
| --- | --- |
| `start` | 전투 시작 |
| `allyTurn:아이디` | 그 부원의 첫 차례 |
| `enemyTurn:N` | N번째 적 차례부터, `event`를 실행할 수 있는 첫 차례 |
| `break` / `combo` / `grab` | 처음으로 약점이 터졌을 때 / 협공이 발동했을 때 / 붙잡기를 했을 때 |

`event`로 연출을 넣을 수 있어요. 지금은 `{ "type": "freeze", "target": "jiyu", "turns": 2, "log": "…" }`(그 부원을 얼어붙게 함)만 있어요.

## 스테이지 연결

어떤 스테이지가 어떤 대사 파일을 쓰는지는 `data/stages.json`에 적어요. 대화 스테이지가 끝나면 클리어로 저장하고, 다음 스테이지도 대화면 이어서 바로 시작해요.
